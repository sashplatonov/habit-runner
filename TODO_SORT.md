

# Научная база для сортировки привычек

## Ключевые исследования, на которых основан подход

| Исследование | Ключевой вывод |
|---|---|
| **Lally et al., 2010** (European J. of Social Psychology) | Формирование привычки занимает 18–254 дня (медиана 66). Ранние дни — самые уязвимые |
| **Baumeister — Ego Depletion** | Сила воли истощается к вечеру. Вечерние привычки сложнее |
| **Wood & Neal, 2007** | Привычки контекстно-зависимы. Нет стабильного контекста → нет автоматизма |
| **Fogg Behavior Model** | Поведение = Мотивация × Способность × Триггер. Слабое звено = провал |
| **Gardner et al., 2012** | Формирование нелинейно: первые повторения дают максимальный эффект, пропуски в начале — катастрофа |
| **Verplanken & Orbell, 2003** (SRHI) | Автоматичность — главный индикатор "закрепилась ли привычка" |
| **Duhigg — Habit Loop** | Привычки без чёткого вознаграждения угасают |
| **Dai et al., 2014 — Fresh Start Effect** | После пропуска "обнуляется" мотивация, нужен перезапуск |

## Факторы сложности (из мета-анализов)

```
КРИТИЧЕСКИЕ (высокий вес):
├── Completion Rate — % выполнения за последние 30 дней
├── Current Streak vs Critical Period — streak относительно 66 дней
├── Days Since Last Miss — свежий пропуск = красная зона
└── Habit Age — молодые привычки (<21 день) максимально хрупкие

ПОВЕДЕНЧЕСКИЕ (средний вес):
├── Время суток — утро легче, вечер сложнее (ego depletion)
├── Длительность действия — 2 мин vs 60 мин
├── Тип: DO vs DON'T — "не делать" сложнее "делать"
├── Сложность (шаги) — 1 действие vs цепочка
└── Требует перемещения/инвентаря — больше friction = сложнее

КОНТЕКСТУАЛЬНЫЕ (нижний вес):
├── Социальная поддержка — solo сложнее
├── Вариативность выполнения — высокий разброс = нестабильность
└── Категория привычки — исследования ранжируют:
    питание/сон/отказ > спорт/медитация > вода/витамины
```

## Промпт для ИИ-агента

```markdown
# РОЛЬ
Ты — разработчик трекера привычек. Создай систему сортировки,
где привычки, требующие НАИБОЛЬШЕГО внимания пользователя,
отображаются ВВЕРХУ списка.

# НАУЧНАЯ ОСНОВА (обязательно учти)

## 1. Критический период (Lally et al., 2010)
Привычка формируется в среднем за 66 дней (диапазон 18–254).
Привычки моложе 21 дня — в "красной зоне" (максимальная хрупкость).
21–66 дней — "жёлтая зона". Старше 66 дней — начало автоматизма.
Вес: habitAgeDays → чем меньше, тем выше приоритет.
Формула: ageFactor = 1 - min(habitAgeDays / 66, 1)

## 2. Процент выполнения (completion rate за 30 дней)
Из мета-анализа Gardner et al., 2012: каждый пропуск в ранний
период значительно замедляет автоматизацию.
Вес: completionRate → чем ниже, тем выше приоритет.
Формула: completionFactor = 1 - completionRate
(где completionRate — число от 0 до 1)

## 3. Текущий streak относительно критического периода
Streak = основной индикатор "набранной инерции".
Потеря streak'а в первые 66 дней — почти перезапуск.
Формула: streakFactor = 1 - min(currentStreak / 66, 1)

## 4. Время с последнего пропуска (Fresh Start Effect — Dai, 2014)
Если пропуск был недавно (1–3 дня назад), привычка в зоне риска
"полного отказа". Нужно немедленное внимание.
Формула: 
  if (daysSinceLastMiss <= 3) missFactor = 1.0
  else if (daysSinceLastMiss <= 7) missFactor = 0.7
  else if (daysSinceLastMiss <= 14) missFactor = 0.4
  else missFactor = 0.1
  if (neverMissed) missFactor = 0.0

## 5. Истощение воли — время суток (Baumeister ego depletion)
Вечерние привычки объективно сложнее из-за усталости
ресурса самоконтроля.
Формула:
  morning (5-11) → timeFactor = 0.0
  afternoon (12-16) → timeFactor = 0.3
  evening (17-21) → timeFactor = 0.6
  night (22-4) → timeFactor = 0.9

## 6. Длительность действия (Fogg: Ability dimension)
Чем дольше привычка, тем больше "friction" и ниже Ability.
Формула: durationFactor = min(durationMinutes / 60, 1)

## 7. Тип привычки: DO vs DON'T (Quinn et al., 2010)
"Не делать" (abstinence) привычки сложнее "делать" привычек.
Они требуют постоянного подавления, что истощает волю.
Формула: typeFactor = isDontHabit ? 0.3 : 0.0

## 8. Сложность действия (количество шагов)
Многошаговые привычки сложнее автоматизировать
(Wood & Neal, 2007: автоматизм = простые повторяемые действия).
Формула: complexityFactor = min((steps - 1) / 5, 1) * 0.3

## 9. Категорийная сложность (мета-данные из исследований)
Базовая сложность по категориям (эмпирические данные):
  diet/nutrition: 0.9
  sleep: 0.85
  quit/abstinence: 0.95  
  exercise: 0.6
  meditation/mindfulness: 0.55
  reading/learning: 0.4
  hydration: 0.15
  medication/vitamins: 0.1
  journaling: 0.35
  social: 0.5
  cleaning/organization: 0.45
  default: 0.5

## 10. Вариативность (consistency score)
Стандартное отклонение интервалов между выполнениями.
Высокая вариативность = нестабильная привычка.
Формула: varianceFactor = min(stdDevOfGaps / 3, 1)

# ИТОГОВАЯ ФОРМУЛА ПРИОРИТЕТА

priorityScore = 
  ageFactor        * 0.20 +   // Критический период
  completionFactor * 0.25 +   // Процент выполнения (главный)
  streakFactor     * 0.15 +   // Текущая серия
  missFactor       * 0.15 +   // Свежесть пропуска
  timeFactor       * 0.05 +   // Время суток
  durationFactor   * 0.05 +   // Длительность
  typeFactor       * 0.05 +   // DO vs DON'T
  complexityFactor * 0.03 +   // Сложность
  categoryFactor   * 0.05 +   // Категория
  varianceFactor   * 0.02     // Стабильность

Сортировка: DESC по priorityScore (высший = требует больше внимания)

# ТРЕБОВАНИЯ К КОДУ

1. TypeScript / JavaScript
2. Каждый фактор — отдельная чистая функция с JSDoc комментарием,
   ссылающимся на исследование
3. Интерфейс Habit:
   {
     id: string
     name: string
     category: string
     type: 'do' | 'dont'
     scheduledTime: 'morning' | 'afternoon' | 'evening' | 'night'
     durationMinutes: number
     steps: number
     createdAt: Date
     completionLog: Date[]     // даты выполнения
     missLog: Date[]           // даты пропусков
   }
4. Функция sortByScientificPriority(habits: Habit[]): ScoredHabit[]
   возвращает массив с полем score и breakdown (значение каждого фактора)
5. Добавь функцию getInsight(habit: ScoredHabit): string
   — текстовую рекомендацию на основе доминирующего фактора:
   Например: "Эта привычка в критическом периоде формирования 
   (день 12 из 66). Каждый день на счету — не пропускай."
6. Покрой юнит-тестами 3 сценария:
   — Новая привычка с пропуском вчера (должна быть вверху)
   — Старая стабильная привычка (должна быть внизу)
   — Средняя привычка с нестабильным графиком
7. Без внешних зависимостей, только стандартная библиотека
```

## Визуальная схема приоритизации

```
SCORE: 0.85-1.0  🔴 КРИТИЧНО
│ Новая привычка + свежий пропуск + низкий completion rate
│ → "Ты в зоне срыва. Сделай минимальную версию прямо сейчас"
│
SCORE: 0.60-0.84 🟠 ТРЕБУЕТ ВНИМАНИЯ  
│ Молодая привычка ИЛИ падающий streak ИЛИ вечернее время
│ → "Привычка ещё не закрепилась. Подготовь триггер заранее"
│
SCORE: 0.35-0.59 🟡 НОРМАЛЬНО
│ Средний возраст + стабильный completion rate
│ → "Хороший прогресс. Продолжай в том же ритме"
│
SCORE: 0.00-0.34 🟢 АВТОПИЛОТ
│ Старая привычка + высокий streak + утреннее время
│ → "Привычка почти автоматическая. Можно усложнить"
```
